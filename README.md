# Basket Esteban Mateo

Jeu de basket style Pixar, jouable dans le navigateur (iPhone, Android, ordinateur).

**Jouer :** https://am3su.github.io/basket-esteban-mateo/

## Contenu
- `index.html` : le jeu.
- `vendor/` : moteur 3D (three.js r128) et effets lumineux.
- `assets/sprites/` : images animées haute définition des 4 joueurs (Mateo, Esteban, Sami, Lina).
- `assets/video/` : vidéo d'ouverture, intros de Mateo et Esteban, public (applaudissements et bras levés).
- `assets/img/` et `assets/poster.js` : cartes du menu et images de secours.
