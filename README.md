# Basket Esteban Mateo

Jeu de basket style Pixar, jouable dans le navigateur (iPhone, Android, ordinateur).

**Jouer :** https://am3su.github.io/basket-esteban-mateo/

Tous les fichiers sont à la racine : `index.html` (le jeu), `three.min.js` et `postfx.js` (moteur 3D et effets),
`sprites_*.js` (images des joueurs), les vidéos `.mp4` et les images `.jpg`.
